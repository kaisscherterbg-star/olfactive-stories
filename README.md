# Olfactive Stories

Site vitrine et boutique de parfums de niche (page unique `index.html`).

- Hébergé sur Netlify, déployé automatiquement à chaque mise à jour de la branche `main`.
- `index.html` : le site ; `assets/` : visuels ; `vendor/` et `support.js` : bibliothèques d'exécution.
- Aucune commande de build : le dossier racine est publié tel quel (voir `netlify.toml`).
